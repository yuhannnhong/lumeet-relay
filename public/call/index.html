聲音

到 elevenlabs.io 挑聲音或複刻自己的聲音，複製 Voice ID 貼到下面。中國大陸無法使用。

到 MOSS 官網（大陸版、海外版都可以）的音色庫挑聲音，或自己建立音色，複製音色 ID 貼到下面。中國大陸可以直連。

到 MiniMax 開放平台建立 API Key，在音色庫挑聲音或複刻自己的聲音，複製音色 ID（voice_id）貼到下面。大陸版和國際版是兩個不同的帳號，Key 不通用，下面要選對。

AI 接入方式

填入模型 API（OpenAI 相容格式），App 直接呼叫。

讓 Claude Code、Codex 等用訂閱帳號接入，不用模型 API。需要先部署 MCP 橋接（見說明文件）。

填好上面兩格再按，貼到你的 AI 那邊（Claude Code、Codex、Operit⋯⋯的 MCP 設定）。網址含密碼，不要給別人看。

語音辨識（選填）
